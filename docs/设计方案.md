# 知序 · 99 / 300 题双版本人格探索网站设计方案

日期：2026-10-16；版本：设计稿 v2。  
状态：方案与交互原型审阅；未连接服务器、未部署。  
拟部署服务器：172.29.20.105；系统、资源、已有服务与端口待获准后检查。  
产品暂定名：知序 · SELF ATLAS。

## 1. 产品与用户流程

面向使用手机、平板和电脑的中文用户，提供两个清晰入口：**精简测试 99 题**与**详细测试 300 题**。两版完成后都提供具体建议；详细版在四维人格探索基础上，增加人格深化、职业发展、社交关系和恋爱关系的专项情境题与专项建议。

详细版的 300 题为总题数，包含精简版的 99 题，再增加 201 题。已完成精简版的用户，可以选择沿用相同题库版本的 99 题答案，只补答 201 题；开始前显示原答题日期，也允许重新开始。不同版本不静默套用旧答案，后台须有明确兼容映射才允许迁移。

用户路径：选择版本 → 阅读题量、预计时长和保存方式 → 分章节作答 → 检查漏题 → 生成对应深度报告 → 阅读优先建议 → 保存报告或继续详细探索。

沿用免费、免注册的默认定位；不要求姓名、手机号、学校、单位或伴侣身份，不设置报告付费墙。采用原创题目与原创解释，标注“MBTI 风格人格探索”，不宣称官方量表、医学诊断或已验证的预测能力。题量增加不自动意味着准确率提高；正式题库需内容审阅和试测。

## 2. 两种测试的范围

| 项目 | 精简测试 | 详细测试 |
| --- | --- | --- |
| 总题量 | 99 题 | 300 题，包含前述 99 题 |
| 初始预计时间 | 15–25 分钟 | 累计约 50–80 分钟，可分次完成 |
| 主要内容 | I/E、S/N、T/F、J/P 四维偏好 | 四维深化＋职业＋社交＋恋爱 |
| 章节 | 4 个小节，25 / 25 / 25 / 24 题 | 5 大章节、14 个小节，每小节约 20–25 题 |
| 完成后报告 | 四维分析、边界解释、优势盲点、具体建议与 7 天行动 | 基础内容＋专项观察与建议＋30 天行动 |
| 升级 | 可沿用同版本答案进入详细测试 | 已有 99 题时仅补答 201 题 |

时间是设计估算，上线前由试测校正，休息时间不计入预计答题时间。首页保留“精简测试”名称，同时醒目标出 99 题与预计时长。

### 精简版 99 题

| 维度 | 正向计分端 | 题数 |
| --- | --- | --- |
| I / E：能量与互动偏好 | E | 25 |
| S / N：信息获取与关注方式 | S | 25 |
| T / F：决策与价值取舍 | T | 25 |
| J / P：计划、开放与行动方式 | J | 24 |
| 合计 | | 99 |

99 不能被 4 整除，各维按自身题数归一化，不比较原始总分。每维涵盖多个日常情境，正反向题尽量平衡，不用无关题凑数。

### 详细版 300 题

| 章节 | 题数 | 累计 | 输出 |
| --- | --- | --- | --- |
| 基础人格 | 99 | 99 | 与精简版相同的四维基线 |
| 人格深化 | 21 | 120 | 补充情境与扩展四维观察 |
| 职业发展 | 60 | 180 | 工作价值、环境偏好、协作、发展建议 |
| 社交关系 | 60 | 240 | 联系节奏、表达支持、边界与分歧处理 |
| 恋爱关系 | 60 | 300 | 亲密与独立、表达回应、冲突修复、期待协商 |
| 合计 | 300 | | 完整深度报告 |

人格深化 21 题按 E/I 5、S/N 5、T/F 5、J/P 6 分配，与前 99 题合并后，四个人格维度各 30 题，总计 120 题。后三类 180 题只用于专项分析，不混入 MBTI 四维分数。

每个专项 60 题，按 6 个观察主题、每主题 10 题规划；主题是原创内容蓝图，尚非经过验证的独立心理分量表。

- **职业发展**：兴趣与价值线索、结构与自主、协作与反馈、学习成长、决策与不确定性、任务负荷与边界。
- **社交关系**：互动节奏与关系深度、自我表达、倾听支持、信任建立、人际边界、分歧处理。
- **恋爱关系**：亲密与独立、表达与回应、信任与边界、冲突修复、共同决策、生活期待与承诺协商。

300 题全部有明确用途，避免同义改写或重复填充。正式发布前检查题意、重复度、作答负担与回答分布；不在原型阶段宣称信效度。恋爱题不要求必须有伴侣，职业题兼顾学习与项目场景。

## 3. 手机、平板和电脑的最终呈现

使用同一网址、自适应布局，无需安装应用。横竖屏与窗口变化只改变排版，不丢进度，不重置答案。

| 设备 | 首页 | 答题 | 报告 |
| --- | --- | --- | --- |
| 手机 | 两种测试入口纵向排列 | 单题，大号文字选项，清晰的进度与上一题 / 下一题 | 单列阅读，章节导航自动换行，图表配文字解释 |
| 平板 | 空间充足时双入口并排 | 居中题卡、触控选项，适配横屏、竖屏与分屏 | 摘要与正文随可用宽度重排 |
| 电脑 | 双入口展示题量、时间与内容区别 | 居中题卡，宽屏附章节目录，支持键盘 | 章节目录与正文，方便长报告阅读和打印 |

按可用宽度与触控方式适配，不按设备名称锁死。覆盖 320px 起的窄屏、平板分屏、横竖屏与宽屏；操作不依赖悬停；触控有效区域至少约 44×44px。

视觉沿用纸白、松针绿、清晰正文与节制动效。首屏就能选择 99 / 300，不在答题后才告知题量。

## 4. 长问卷的答题体验

1. 开始说明按近半年的通常行为回答；未知或无经历的情境不要编造经验。
2. 常规题采用 7 级量表，从“非常不符合”到“非常符合”；避免双重否定、诱导和道德评价。
3. 职业 / 恋爱经验题提供“不适用 / 无相关经历”。单身用户仍可回答需求与边界题，在校用户可回答学习 / 项目情境。
4. 每屏一题，选择后点下一题；显示总进度、所在章节、小节进度、已答数与漏题定位，支持回看修改。
5. 每次选择自动保存本机草稿并显示保存状态；刷新、退出、网络中断和横竖屏切换后可继续。
6. 精简版按 25 / 25 / 25 / 24 分 4 小节；人格深化单独 21 题；三个专项各分 3 组 × 20 题，总计 14 小节。
7. 每小节后给可跳过的休息提示，不设置强制倒计时，不催促用户作答。
8. 详细版到第 99 题时可查看精简报告并保存继续；未完成 300 题时不生成未答专项的结论。
9. 从精简版升级时已有 99 题标记已完成，从第 100 题开始，剩余 201；允许回看修改，并按最终答案重算。
10. 提交前检查漏题；“不适用”算已响应，但不参与相应主题分数。断网或提交失败保留答案，幂等重试避免重复历史。

### 跨设备继续

响应式适配与跨设备同步是两件事。默认草稿只保证同一浏览器恢复，不承诺自动同步到其他设备。

额外规划“换设备继续”：用户主动开启后，服务器临时保存加密草稿，生成续答链接 / 二维码，有效期 7 天，可手动撤销，完成后删除临时副本。另一设备恢复版本、答案与进度，无需注册。页面说明仅在自己的设备上使用，不公开转发。

续答凭证至少 128 位随机值，不使用可枚举短数字码；放 URL fragment，访问日志不记录凭证和答案。两设备同时修改时通过修订号检测冲突，不能静默覆盖较新答案。未主动启用跨设备继续的用户，原始答案不长期保存到服务器。

## 5. 完成后提供的详细建议

报告先给出“最值得关注的 3 件事”，再提供分章节展开内容。依据具体回答、强弱倾向、边界和专项观察组合建议；相同类型不应仅收到完全相同的套话。

### 精简报告

四维偏好与边界说明、日常表现、优势与可能盲点、学习 / 工作习惯、基础沟通建议、3 条优先行动与 7 天练习。其职业和关系提示仅限于四维线索，不能声称完成专项评估。

### 详细报告

1. **总览与优先行动**：核心观察、候选类型与最重要的 3 条具体建议。
2. **四维分析**：保留 99 题基线，展示 120 题人格部分的扩展观察；若变化，说明边界与新增回答影响。
3. **人格与日常情境**：优势、盲点、情境变化、行动和压力观察。
4. **职业发展**：工作价值、环境偏好、协作方式、可能耗能情境、可验证的职业探索与技能练习。
5. **社交关系**：联系频率、朋友圈经营、自我表达、倾听支持、边界与冲突建议。
6. **恋爱关系**：亲密和独立需求、表达回应、信任、修复、共同期待与单身 / 关系中都可做的练习。
7. **学习与恢复**：有效学习条件、日常负荷与恢复节奏。
8. **30 天行动计划**：四周小任务、复盘问题、可观察指标，不同时堆给用户几十条要求。
9. **如何理解结果**：题库 / 算法 / 模板版本、有效题量、不适用数量、边界与证据不足主题。

核心建议统一采用：**观察依据 → 可能出现的场景 → 具体行动 → 复盘方法**。使用条件性描述，给用户核对与调整的空间。

| 领域 | 示例观察 | 具体行动 | 复盘 |
| --- | --- | --- | --- |
| 职业 | 更愿意独立梳理，再参与讨论 | 会前写一页观点；用一个短期项目检验研究、内容或策划兴趣 | 两周记录投入感、疲劳点和真实反馈 |
| 社交 | 重视深度关系，连续群体互动后更疲惫 | 主动约定联系频率，活动后预留安静间隔 | 回看关系质量和精力，调整节奏 |
| 恋爱 | 需要空间，也重视稳定回应 | 用“我需要独处到几点，之后主动联系”协商具体安排 | 检查双方是否理解、能否执行、是否要修改 |

不由人格类型宣判命定职业、招聘结论、伴侣匹配分、忠诚或关系结局；恋爱模块不未经验证就诊断依恋或心理问题。

网页报告支持章节阅读、打印 / 另存 PDF，以及用户主动选择内容的摘要图片。完整报告默认私有，不生成公开分享链接。草稿与最近 10 份报告保存在本机历史，可逐项删除或清空。

## 6. 计分与建议规则

七级答案映射 -3 至 3，乘 direction 后统一正向为 E、S、T、J。四维分别归一化：P = 100 × (Σ keyed_score + 3n) / (6n)，n 为该维题数；另一端为 100 - P。精简版 n 为 25 / 25 / 25 / 24，详细版人格部分 n 为每维 30。

使用未舍入值判定边界；45–55 标为接近均衡，这是解释规则而非统计置信区间；恰好 50 显示 X，不随机打破平局。全中立显示缺乏明显偏好。百分比不是准确率、能力、人口百分位或置信概率。

各专项主题独立定义含义与方向，不混成“职业能力分”“社交能力分”或“恋爱分”。“不适用”不按中立或零分计；每主题 10 题中至少 7 道有效回答才给描述性位置，否则标为信息不足，仅给通用反思问题。7 / 10 为初始覆盖规则，需试测审阅，不是信度保证。

快速作答、长串同选项或情境差异仅形成柔和回顾提示，不自动判定作弊、改分或医学结论。报告显示有效覆盖，不宣传准确率。

后端按版本化评分规则与经过审阅的建议库生成报告。建议包含主题、触发条件、证据、适用场景、行动、复盘与排除条件；冲突线索按不同情境解释，不输出互相矛盾的确定断言。精简版不触发依赖专项答案的规则。

相同版本和相同答案必须生成相同数值。题库、计分、建议与模板分别带版本，不依赖在线 AI 即可生成完整报告；如未来增加 AI 润色，不允许改分或捏造回答依据。

## 7. 技术、后台与数据

独立项目采用 Vue 3 + TypeScript + Vite、FastAPI、PostgreSQL、Nginx 和 Docker Compose，不与实验室官网共用题库、账号或数据库。

| 页面 / 接口 | 用途 |
| --- | --- |
| `/` | 99 / 300 双入口 |
| `/test?mode=basic`、`/test?mode=full` | 两条测试、说明、章节与恢复 |
| `/report`、`/history` | 对应报告与本机历史 |
| `/resume` | 主动跨设备恢复 |
| `/types`、`/types/:code` | 16 类型参考库 |
| `/admin` | 后台 |
| `GET /api/questionnaires/current?mode=...` | 题目与版本，不发送评分键 |
| `POST /api/assessments/score` | 校验模式、版本、题目与范围并计分 |
| `/api/resume-sessions/*` | 创建、修订、凭证恢复、撤销和到期清理 |
| `/api/admin/*`、`GET /healthz` | 内容管理与健康检查 |

默认回答、草稿与报告存 IndexedDB；计分提交只在内存处理，不写入长期数据库、日志或错误追踪。仅主动启用跨设备继续时加密临时存储草稿，按到期 / 完成 / 撤销清理，并在界面解释。

后台管理两版题库、共用 99 题映射、维度 / 专项归属、方向、适用范围、建议规则和模板。发布检查题量恰好 99 / 300、共享题版本一致、模块数量正确、规则依赖完整；已发布版本不可原地覆盖，正在作答的人固定原版本。统计按天聚合两版开始与完成、章节中止位置，不保存原始答案或个人身份。

## 8. 确认后的实施与部署

1. 编写与审阅原创 300 题、共用 99 题、专项主题、建议库和模板，再小规模试测与调整。
2. 本地实现响应式双入口、99 / 300 流程、升级、恢复、报告、历史、导出、跨设备与后台。
3. 验证评分、版本复现、建议依据和长问卷恢复；检查浏览器和真实触控设备。
4. 获准后检查 172.29.20.105 系统、资源、已有服务、容器环境、网络和空闲端口。
5. 独立目录建议 `/opt/mbti-site`；入口候选端口 8086 只是规划，以检查结果为准，不覆盖现有服务。
6. 私网地址默认内网访问；面向互联网客户需可用网络入口，具备域名和证书时使用 HTTPS。
7. 备份相关配置后发布、迁移与验收，保留回滚版本和管理数据备份；临时续答草稿不进入长期备份。

低并发可先按 2 核、2 GB 可用内存、10 GB 空间估算，承载量需实测。服务器凭据不写入源码、方案或前端；应用、后台与数据库使用独立凭据。

## 9. 验收

- 两入口明确，题数 99 / 300 正确；升级剩余 201，无重复或漏题。
- 手机 / 平板 / 电脑、横竖屏与分屏可读；320 / 360 / 390 / 768 / 820 / 1024 / 1440px 无溢出，触控与键盘可完成。
- 选择、回看、刷新、重开、断网和旋转不丢草稿；模式切换不覆盖另一草稿。
- 跨设备保持版本与答案；过期 / 撤销失效，并发编辑不静默覆盖。
- 校验不等题数归一化、120 题每维 30、专项不混入四维、反向、中立、X、非法答案与旧版本复现。
- 不适用不计零，覆盖不足可见；精简报告不伪造详细版证据。
- 各建议有具体作答依据、行动与复盘，同类型不同回答有相应区别。
- 未完成模块不产生结论，完成后网页、历史与导出均可用。
- 后台发布检查、旧版本固定、到期清理、重启、备份恢复与回滚可用。

## 10. 本次原型的界限
